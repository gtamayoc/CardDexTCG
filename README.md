# CardDexTCG
CardDexTCG es una aplicación diseñada para organizar cartas de Pokémon TCG de manera eficiente. Permite a los usuarios completar sus colecciones, compartir su catálogo y ver las cartas de sus amigos, incluyendo aquellas que necesitan para sus sets. Una herramienta ideal para coleccionistas y jugadores que buscan gestionar e intercambiar cartas.
